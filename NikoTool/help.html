使用帮助

Help · how to use these tools

这里有站点的基础说明。所有功能都在浏览器里跑，不登录、不上传、不追踪。

01快速开始 Quick start

从主页点任意一个工具卡片进入对应页面。每个工具页面左上角都有“返回主页”链接。

  • 实验室 — 三个标签页：JS 运行、JSON 提取、前端三件套
  • 哈希生成器 — SHA-256 / SHA-1 / SHA-512 / MD5
  • 生成器合集 — 个人主页 / README / 配色方案

02快捷键 Shortcuts

  • Ctrl + Enter — 运行当前输入框的内容
  • Tab — 在编辑区插入两个空格缩进

03实验室三个标签 Lab tabs

JS 运行：在独立线程中执行 JavaScript，支持 await 和 return。即使写了死循环，也会被超时机制强制终止，不会卡住页面。

JSON 提取：解析、格式化、压缩 JSON。支持路径查询，比如输入 tags[0] 或 meta.vip 直接取嵌套的值。解析出错会告诉你在第几行第几列。

前端三件套：HTML、CSS、JS 三块输入，右边立刻出效果。页面内的 console.log 会桥接到下方的输出区。

04数据与隐私 Privacy

  • 所有计算在你的浏览器本地完成，不上传服务器
  • 输入内容通过 localStorage 保存在本机，下次打开还在
  • 清除浏览器数据会同时清掉这些保存内容
  • 没有登录、没有广告、没有追踪脚本

05常见问题 FAQ

为什么我的 JS 跑不出结果？ 检查是否写了 return，或者看输出区有没有报错信息。

为什么 JSON 解析失败？ 常见原因：用了单引号、多了逗号、键名没加引号。输出区会给你出错位置。

生成的 HTML 下载后打不开？ 检查文件后缀是不是 .html，双击用浏览器打开就行。
