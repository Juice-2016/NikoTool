# NikoTool Lite

纯前端的浏览器工具集合，所有计算都在本地完成，不上传任何数据。

🔗 **在线访问**：https://juice-2016.github.io/NikoTool/

---

## 工具

| 工具 | 功能 |
|---|---|
| **实验室** | JS 运行 / JSON 提取 / 前端三件套运行器 |
| **哈希生成器** | SHA-256 / SHA-1 / SHA-512 / MD5 |
| **生成器合集** | 个人主页 / README / 配色方案 |

---

## 技术栈

- 纯 HTML / CSS / JavaScript
- 无框架、无依赖、无构建步骤
- 使用 Web Worker 隔离 JS 执行
- 使用 iframe 沙箱预览前端代码
- 数据通过 `localStorage` 本地保存

---
